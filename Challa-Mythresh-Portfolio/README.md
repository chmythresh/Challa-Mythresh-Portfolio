# Challa Mythresh Portfolio
Adapted from the supplied portfolio source. Verify permission before public redistribution.

## Run
Open the folder in VS Code and use Live Server, or run `python -m http.server 5500` and open http://localhost:5500.

## Add your media
Replace assets/img/profile-placeholder.svg with your own image by updating the poster in index.html. Put profile.mp4 in assets/video, add `<source src="assets/video/profile.mp4" type="video/mp4">` inside the video, and remove hidden from the about toggle. Add project and event images inside the media placeholders.
Add your actual email, LinkedIn, and resume links before publishing. Contact form is intentionally disabled until configured. Verify project ownership, skills, and event status.
